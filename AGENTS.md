# Weather App — Instrucciones del proyecto

## Objetivo
Desarrollar una aplicación web de clima que consuma la API pública Open-Meteo.

## Stack
- HTML5 semántico
- CSS3 responsive
- JavaScript ES Modules
- Fetch API
- Git

## Restricciones
- No utilizar frameworks.
- No agregar dependencias innecesarias.
- No utilizar credenciales para Open-Meteo.
- No implementar backend.
- No modificar archivos sin revisar la SPEC
- Preguntar antes de ejecutar el código

## Arquitectura
Separar presentación, lógica de aplicación y comunicación con API cuando aporte claridad.

## Fuente de datos
- Open-Meteo Geocoding API
- Open-Meteo Forecast API

## Proceso de trabajo
1. Leer specs/ antes de programar.
2. Presentar el plan en modo Plan.
3. Implementar una tarea por vez.
4. Revisar los cambios con git diff.
5. Probar la funcionalidad.
6. Crear commits por avance estable.

## Documentación
Actualizar este archivo cuando cambie una decisión de arquitectura.
